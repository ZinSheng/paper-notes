# GlobalDentBench example

This self-contained, privacy-safe demo shows the same GlobalDentBench close-reading workflow in HTML and Obsidian.

## HTML

Open `html/dashboard.html` in a browser. The `html/` directory contains the dashboard, GlobalDentBench paper page, fictional `Clinical AI Evaluation Demo` research page, local fonts, and five paper figures.

## Obsidian

Open the `obsidian/` directory as an Obsidian vault, then start from `Dashboard.md`. The vault includes the paper note, a fictional research page, a reading heatmap, and its own copy of the five paper figures.

All Zotero identifiers, annotation timestamps, reading activity, and research-project details in this example are synthetic. The paper metadata, analysis, and figures describe the public GlobalDentBench paper.
